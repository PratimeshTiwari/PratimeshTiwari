### What I'm into

Agentic AI and the unglamorous plumbing around it — orchestration, context management,
tool protocols, and terminal UIs. Most of my time goes into making an LLM behave like a
teammate instead of a chat window. The rest goes into backends: APIs, schemas, and the
boring reliability work that decides whether any of it survives contact with users.

I show up for hackathons whenever there's one worth losing a weekend to.

### Things I'm building

**[Gemini-Agent](https://github.com/PratimeshTiwari/Gemini-Agent)** · JavaScript, Node, React/Ink
A Claude Code-style coding agent with **no LLM API client**. Instead of keys and billing, it
drives a real browser tab: a Node server talks over WebSocket to a Chrome extension, which
types the prompt into your own Gemini / ChatGPT / Claude session and streams the reply back.
Everything stays local.
- Single / duo / swarm agent topologies — reviewer and reasoner subagents run in parallel across separate tabs
- Workspace RAG: AST chunking, a local TF-IDF index, and a token budget that actually gets enforced
- Per-hunk diff approval with backups and undo; risk-classified shell commands with a persistent allowlist
- A GitHub PR agent, an MCP tool server, and a VS Code companion that tells the agent where your cursor is
