## Highlights

### [Agent CLI](https://github.com/PratimeshTiwari/Agent-CLI)

A Claude Code-style coding agent for the terminal, with **no API key**. It drives a Gemini tab in
your own Chrome through a small extension. The agent reads, searches, edits as diffs you approve,
runs commands, and compacts long sessions by itself.

<img src="assets/agent-cli.svg" alt="Agent CLI documenting two models into a Markdown file" width="100%">

`Node.js` `React/Ink` `Chrome MV3` `WebSockets` `VS Code extension`

### [Agentic Interview Mate](https://github.com/PratimeshTiwari/cf_ai_agentic_interview_mate)

An AI interviewer that runs mock interviews by voice or chat, scores each answer as you speak,
flags answers that look read out or AI-written, and remembers you between sessions. It runs
entirely on Cloudflare.

<img src="assets/interview-mate.jpg" alt="Agentic Interview Mate: live agent log, the interviewer's reply, and the coding workspace" width="100%">

`TypeScript` `Workers` `Durable Objects` `Workflows` `Workers AI` `Vectorize` · earlier version: [AI-Interview-Agent](https://github.com/PratimeshTiwari/AI-Interview-Agent)
